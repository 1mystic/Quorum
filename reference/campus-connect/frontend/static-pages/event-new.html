Publishing checklist

1 Fill in all fields. A clear description gets better registrations.
2 Set a realistic capacity. Registered students receive a confirmation ID.
3 Once published, all members of your club can see and register for the event.
4 On the day, use the Attendance page to mark who actually showed up.
5 After the event, set results. Certificates are auto-generated for all attendees.
! You can edit or cancel the event anytime before it starts.
